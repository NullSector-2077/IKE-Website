# I.K.E. Official Website

Static, responsive homepage for I.K.E. Browser. The site is written in HTML, CSS and JavaScript and requires no build step.

## Deployment

The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`. In the repository settings, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. Every push to `main` will then publish the site automatically.

Expected project-site address:
https://nullsector-2077.github.io/IKE-Website/

## Notes

- The hero browser window and protection panel are interface illustrations, not live browser output.
- The protection count shown in the illustration is sample data, not a live counter.
- Current availability is described as Arch Linux and CachyOS, 64-bit.
- The logo is served from the I.K.E. Browser repository.
- The site contains no analytics, tracking scripts, backend or forms.
- Confirm release notes and package availability on the browser repository before installing.
